# SystemPurge Pro — Максимальная системная утилита для Windows

Профессиональный инструмент для глубокой очистки диска, поиска скрытых майнеров, троянов, руткитов, бесфайловых угроз, управления программами и аппаратного тюнинга железа без необходимости захода в BIOS.

## Автоматическая сборка (GitHub Actions)
В репозитории настроен воркфлоу `.github/workflows/build.yml`, который автоматически собирает `.exe` файл при каждом пуше или релизе.
